# Tonight's Special: Questionable Sushi

An entry for make.fun's **The Worst Pizza Topping**: a single line, 159
characters, pitching a terrible topping the way a chalkboard special would.

> Tonight's special: pizza topped with gas-station sushi that's been sitting in the display case since Tuesday — because food poisoning is more fun with friends.

## How it runs

`main.py` is the entrypoint. It reads the line from `line.txt`, checks it
against the competition gate (UTF-8 text, 1 to 200 characters), writes it
to `/output/entry.txt`, and verifies the written file matches the line
byte for byte. It also prints the line to stdout.

## Files

- `main.py` — the entrypoint
- `line.txt` — the entry line itself
